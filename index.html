ABOUT THIS REFERENCE

Windows shortcuts, organized clearly.

This website is an independent reference designed to make Windows keyboard shortcuts easier to discover, understand and remember.

The reference covers commonly documented Windows 10 and Windows 11 shortcuts, including system controls, File Explorer, window management, virtual desktops, taskbar controls, accessibility, screenshots, text editing and more.

Some keyboard shortcuts can behave differently depending on the application or Windows configuration.
